# GLAB320H21 – Simple React Application

This project was created for the GLAB320H.2.1 lab assignment. It demonstrates a basic understanding of building and rendering React components using `create-react-app`.

## What I built

- A simple React app with custom components
- Components: Header, Content, Footer
- Used props to pass dynamic data and inline styles
- Rendered all components within the main `App` function

## How to run it

1. Clone the repository  
   `git clone https://github.com/YOUR_USERNAME/GLAB320H21.git`

2. Navigate into the project folder  
   `cd GLAB320H21`

3. Install dependencies  
   `npm install`

4. Start the development server  
   `npm start`

This will open the app in your browser at `http://localhost:3000`.

## Notes

This is a beginner project focused on practicing core React concepts. Components are currently all written in a single file (`App.js`). I plan to refactor into separate files and explore additional styling methods if time allows.
